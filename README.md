# 🌌 AURA AI: Neural Receptionist Dashboard

A high-performance, real-time AI dashboard for managing WhatsApp and Voice interactions using Gemini 1.5 Flash.

## 📦 System Architecture

| Module | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | React (Vite) + Tailwind | Glassmorphism Dashboard |
| **Neural Core** | Google Gemini 1.5 Flash | AI Intelligence |
| **Voice Engine** | Vapi WebSockets | Real-time Voice Stream |
| **Backend** | Vercel Serverless | WhatsApp Webhook Handling |

## 🚀 Key Features

- **3x3 Neural Grid**: Compact control for all system modules.
- **Full-Width Live Stream**: Real-time transcript of all voice sessions.
- **Zero-Latency**: Optimized for near-instant responses.
- **Secure Link**: AES-256 encrypted neural communication.

## 🛠️ Setup Instructions

1. **Environment Variables**:
   ```env
   GEMINI_API_KEY=your_key
   VITE_WHATSAPP_PHONE_NUMBER_ID=your_id
   VITE_WHATSAPP_ACCESS_TOKEN=your_token
   ```
2. **Installation**:
   ```bash
   npm install
   npm run dev
   ```
